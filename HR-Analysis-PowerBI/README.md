# HR Analysis Dashboard (Power BI)

## Objective
Analyze employee data to understand attrition and hiring trends.

## Tools Used
- Power BI
- Excel

## Features
- KPI metrics
- Attrition analysis
- Hiring trends
  
## Insights
- Higher attrition observed in specific departments
- Majority of employees fall within a particular age group
- Certain job roles show higher turnover trends
